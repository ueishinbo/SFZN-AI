# COMAC AI 前端原型

面向智能体桌面应用的高保真前端原型。当前阶段只实现前端界面与 Mock 交互，不代表真实后端业务口径。

## 启动

```bash
npm install
npm run dev
```

启动后访问终端中显示的本地地址，默认通常为 `http://localhost:5173`。

## 已实现

- 截图风格的桌面端布局
- 左侧任务、专家、自动化导航，以及右上角全局助理模式入口
- 最近任务与自动化任务列表
- 自动化分组展开和收起
- 侧边栏收起和恢复
- 智能体任务输入器及发送状态
- 点击任务后的前端 Mock 状态切换
- 自动化任务列表、创建和编辑
- 自动化任务暂停、恢复、删除和立即执行
- 模拟执行状态、运行记录及结果详情
- 浏览器本地持久化
- 助理固定长 Session、对话内协作任务查询与非阻塞 A2A 结构化行动卡
- 任务/助理整套工作区切换：助理模式使用独立侧边栏，包含唯一“我的助理”和 A2A 单聊/群聊列表
- A2A 采用多人通知、多人协作、单人协作、单人通知四组；新建会话从“我的助理”发起，已有会话通过右侧私人分身对话发送和确认
- A2A 会话页只读；群聊协作中的分身严格按顺序各回答一次，协作型会话跟踪目标、轮次和回复进度
- 私人助理与群聊保持独立运行；助理忙碌时建群请求排队，已有群聊仍可使用
- 独立后台管理模式：支持从助理进入并返回原现场，包含概览统计、资源、运行、审批、权限和系统管理的前端 Mock 页面
- A2A 确认与连续澄清共用配置驱动的 Action Card：非末步“继续”，澄清末步“提交”，外部动作使用受控“确认……”文案
- A2A 单卡派任务表单、仅对 C 任务展示业务标记、后台动态 Schema、自然语言修订草稿与明确按钮授权
- 三字段可编辑催办卡，以及支持补充回复的发起方/接收方长会话视角切换
- 模型输出结束后再插入行动卡，并与 Workspace 任务文件联动
- 助理复杂任务的 SubAgent 协同状态栏、对话区内执行详情、输入阻塞、部分失败与整轮重新执行
- 普通任务与助理共用 Codex 风格 Workspace 工作台：双层导航、标签、输出物浮层、独立文件目录与响应式交互
- 受控 HTML Browser：只运行自己生成的 HTML，支持刷新和查看源文件，不允许输入网址
- 普通任务 Session 目录：`context.md`、`attachments/` 与生成物 `outputs/`
- 助理目录：规则、用户偏好、长期记忆、每日工作记忆、任务文件与输出物
- 通过自然语言从协作任务创建自动催办
- 宽屏、窄屏和移动端适配

## 工程结构

- React + TypeScript
- Vite
- Lucide 图标库

真实接口、任务执行流、会话持久化、模型调用和账号体系尚未接入。
