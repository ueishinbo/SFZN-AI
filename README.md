# COMAC AI 前端原型

面向智能体桌面应用的高保真前端原型。当前阶段只实现前端界面与 Mock 交互，不代表真实后端业务口径。

## 启动

```bash
npm install
npm run dev
```

启动后访问终端中显示的本地地址，默认通常为 `http://localhost:5173`。

## 已实现

- 截图风格的桌面端布局
- 左侧任务、助理、专家、自动化导航
- 最近任务与自动化任务列表
- 自动化分组展开和收起
- 侧边栏收起和恢复
- 智能体任务输入器及发送状态
- 点击任务后的前端 Mock 状态切换
- 自动化任务列表、创建和编辑
- 自动化任务暂停、恢复、删除和立即执行
- 模拟执行状态、运行记录及结果详情
- 浏览器本地持久化
- 宽屏、窄屏和移动端适配

## 工程结构

- React + TypeScript
- Vite
- Lucide 图标库

真实接口、任务执行流、会话持久化、模型调用和账号体系尚未接入。
