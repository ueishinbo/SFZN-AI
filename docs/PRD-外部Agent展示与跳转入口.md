# PRD：外部 Agent 展示与跳转入口

> 文档版本：V1.2  
> 文档状态：需求讨论稿  
> 更新日期：2026-08-24  
> 适用端：COMAC AI 桌面 Web / 桌面客户端内嵌 Web  
> 关联模块：左侧全局导航、“更多”菜单、后台 Agent 配置管理

## 1. 文档目的与口径

本文定义 COMAC AI 前台“外部 Agent”页面的产品定位、信息架构、展示字段、跳转规则、异常处理和验收标准。

本期产品口径必须明确：

1. “外部 Agent”页面是一个**展示与访问入口**；
2. 用户从 COMAC AI 点击卡片后，前往第三方平台使用对应 Agent；
3. 前台不提供 Agent 注册、创建、编辑、删除、上下架或排序功能；
4. 外部 Agent 的注册和配置由管理后台负责，不属于本文前台页面范围；
5. COMAC AI 本期不调用外部 Agent API，不传递当前任务或对话内容，也不接收其执行过程和结果；
6. 当前前端 Demo 中的卡片数据可以使用静态 Mock，正式产品必须从服务端读取已发布的 Agent 配置。

## 2. 产品背景

用户可能需要使用部署在不同第三方系统中的 Agent。若这些能力分散在不同平台，用户需要自行保存地址并反复切换，难以形成统一的访问入口。

COMAC AI 已有“新建任务、助理、专家、自动化”等一级功能。本期在左侧导航增加“更多”，并在其下提供“外部 Agent”入口，将经过后台配置和发布的第三方 Agent 以卡片形式集中展示。

该能力解决的是“在哪里找到并打开外部 Agent”，不是“如何在 COMAC AI 内运行外部 Agent”。

## 3. 产品目标

### 3.1 本期目标

1. 为已接入或已登记的外部 Agent 提供统一展示入口；
2. 让用户能够理解每个 Agent 的名称和用途；
3. 用户点击卡片操作后，可以安全、明确地进入第三方平台；
4. 保持页面轻量，不引入前台管理、注册和复杂筛选流程；
5. 通过界面提示明确第三方服务边界，避免用户误以为 Agent 在 COMAC AI 内执行。

### 3.2 成功标准

- 用户可以从左侧导航在两次点击内进入外部 Agent 页面；
- 页面能够正确展示后台已发布且用户有权查看的 Agent；
- 用户可以通过卡片操作打开正确的第三方地址；
- 页面中不存在注册、创建、编辑、删除等前台管理入口；
- 用户能够在跳转前识别这是第三方平台能力。

## 4. 本期范围

### 4.1 包含范围

- 左侧“更多”菜单及展开、收起交互；
- “更多”下的“外部 Agent”导航入口；
- 外部 Agent 页面标题和第三方跳转说明；
- Agent 卡片列表；
- Agent 名称、简介和标题首字头像展示；
- 点击“打开 Agent”后跳转至后台配置的外部地址；
- 加载态、空状态和异常状态；
- 服务端按发布状态和用户可见范围返回数据；
- 跳转地址基础安全校验和审计记录。

### 4.2 不包含范围

- 前台注册外部 Agent；
- 前台创建、编辑、删除、排序或上下架 Agent；
- 用户个人收藏或“我的 Agent”；
- 前台搜索、分类筛选和推荐算法；
- COMAC AI 与第三方平台的统一登录；
- 向外部 Agent 传递当前用户问题、对话、附件或任务上下文；
- 在 COMAC AI 内展示外部 Agent 的运行过程、状态和结果；
- 外部 Agent 的调用计费、额度管理和服务保障；
- 外部 Agent API、A2A、MCP 或其他协议级集成；
- 管理后台的完整产品设计。

如后续需要上述能力，应单独立项，不得在本需求开发过程中默认扩展。

## 5. 术语定义

| 术语 | 定义 |
| --- | --- |
| 外部 Agent | 部署和运行在 COMAC AI 之外，由第三方或其他内部平台提供的 Agent。 |
| 外部 Agent 页面 | COMAC AI 中集中展示外部 Agent 卡片的前台页面。 |
| Agent 卡片 | 展示 Agent 基本信息并提供跳转操作的页面单元。 |
| 跳转地址 | 后台为 Agent 配置的目标 URL，用户点击后在第三方平台打开。 |
| 已发布 | Agent 配置已经通过后台校验并允许在前台展示的状态。 |
| 可见范围 | 后台配置的 Agent 可访问用户范围，如全员、组织或指定用户。 |

## 6. 用户与职责边界

| 主体 | 职责 |
| --- | --- |
| 普通用户 | 浏览可见的外部 Agent，并选择是否前往第三方平台使用。 |
| 后台管理员 | 注册和配置 Agent，维护展示信息、跳转地址、可见范围和发布状态。 |
| COMAC AI 前台 | 展示服务端返回的 Agent，并提供明确、安全的跳转入口。 |
| COMAC AI 服务端 | 根据用户身份、可见范围和发布状态返回 Agent 列表。 |
| 第三方平台 | 承担 Agent 的登录、鉴权、运行、结果展示、数据处理和服务保障。 |

外部 Agent 不继承 COMAC AI 当前任务、助理会话或 Workspace 权限。第三方平台的账号与权限由第三方平台自身管理。

## 7. 信息架构与页面入口

### 7.1 导航结构

```text
左侧全局导航
├── 新建任务
├── 助理
├── 专家
├── 自动化
└── 更多
    └── 外部 Agent
```

### 7.2 导航交互

1. 用户点击“更多”，展开其二级菜单；
2. 再次点击“更多”，收起二级菜单；
3. 用户点击“外部 Agent”，右侧主区域切换为外部 Agent 页面；
4. 当前位于外部 Agent 页面时，“更多”和“外部 Agent”均显示选中状态；
5. 页面切换不得打开新浏览器窗口，只有点击具体 Agent 的跳转操作才打开第三方地址；
6. 左侧菜单收起、刷新或重新进入时，应遵循产品统一导航状态规则。

## 8. 页面设计

### 8.1 页面结构

外部 Agent 页面从上到下包括：

1. 页面标题“外部 Agent”；
2. 一句话说明，例如“从这里前往第三方平台，使用已接入的外部 Agent”；
3. 第三方服务提示，例如“将在第三方平台打开，Agent 的运行和服务由对应平台提供”；
4. Agent 卡片列表。

本期不展示：

- 注册 Agent 按钮；
- “我的 Agent”分组；
- 搜索框；
- 分类筛选器；
- Agent 分类标签；
- 编辑、删除和更多操作菜单；
- Agent 运行状态、调用次数、评分或使用排行。

### 8.2 卡片字段

| 字段 | 必填 | 展示规则 |
| --- | --- | --- |
| Agent 名称 | 是 | 单张卡片内突出展示；过长时最多两行，超出截断。 |
| Agent 简介 | 是 | 描述核心用途；建议不超过 60 个中文字符，最多三行。 |
| Agent 头像 | 是 | 取 Agent 标题去除首尾空格后的第一个字符；使用后台配置的头像底色，无底色时使用系统默认色；不展示来源平台 Logo。 |
| 跳转操作 | 是 | 统一显示为“打开 Agent”，并带外部跳转图标。 |

卡片不得展示所属平台、来源信息或分类标签，也不得展示内部配置 ID、密钥、鉴权参数、完整 URL 或后台备注。

### 8.3 卡片排序

前台不提供排序操作，卡片顺序由服务端返回顺序决定。

后台建议支持 `sort_order` 字段：

1. `sort_order` 数值越小越靠前；
2. 相同排序值按发布时间倒序；
3. 前台不得根据名称、点击量或本地状态重新排序。

### 8.4 布局规则

- 桌面宽屏默认每行展示三张卡片；
- 中等宽度可降为每行两张；
- 窄屏或移动宽度降为单列；
- 同一行卡片保持统一基础高度；
- 简介过长不得撑破卡片或遮挡跳转操作；
- 页面内容超出可视区域时，右侧主区域独立纵向滚动。

## 9. 跳转规则

### 9.1 正常跳转

1. 用户点击“打开 Agent”；
2. 前台读取当前卡片服务端返回的跳转地址；
3. 在新标签页或客户端允许的外部浏览器中打开目标地址；
4. 原 COMAC AI 页面保持不变；
5. 新页面的登录、授权和后续操作由用户在第三方平台完成。

### 9.2 跳转边界

本期跳转不得自动携带：

- COMAC AI 登录令牌；
- 用户姓名、工号、组织和联系方式；
- 当前对话内容；
- 当前任务 ID、提示词和附件；
- Workspace 文件地址或文件内容；
- 任何未在安全方案中明确批准的查询参数。

### 9.3 地址安全

1. 正式产品只允许 `https` 地址；
2. 跳转域名必须经过后台校验，建议使用域名白名单；
3. 禁止 `javascript:`、`data:`、本地文件协议和其他非预期协议；
4. 前端打开新标签页时必须隔离来源窗口，防止第三方页面控制原页面；
5. 地址无效、配置缺失或不符合安全规则时，不执行跳转并显示错误提示；
6. 不得在前端代码中保存第三方账号密码、Token 或密钥。

## 10. 页面状态

### 10.1 加载态

- 获取列表期间展示卡片骨架屏或统一加载状态；
- 加载过程中不得短暂显示无数据空状态；
- 超时后进入异常态，并提供重试操作。

### 10.2 空状态

当服务端返回成功但当前用户无可见 Agent 时，展示：

- 标题：暂无可用的外部 Agent；
- 说明：外部 Agent 由管理员统一配置和发布；
- 不展示注册或创建按钮。

### 10.3 异常状态

| 场景 | 前台处理 |
| --- | --- |
| Agent 列表加载失败 | 显示“加载失败，请重试”，提供重试按钮。 |
| Agent 名称异常为空 | 不展示无标题卡片，由服务端记录并拦截异常配置。 |
| 跳转地址缺失或非法 | 阻止跳转，提示“该 Agent 暂时无法打开”。 |
| Agent 已被后台下架 | 刷新列表后移除；若用户点击时已下架，由服务端或跳转校验返回不可用提示。 |
| 用户无访问权限 | 不返回该 Agent；不得先展示后提示无权限。 |
| 第三方平台不可用 | COMAC AI 不承诺恢复第三方服务，可提示用户稍后重试或联系对应平台。 |

## 11. 服务端数据要求

正式前台建议读取如下最小数据结构：

```json
{
  "id": "agent_001",
  "name": "知识库问答 Agent",
  "description": "连接外部知识库，在第三方平台中进行检索与问答。",
  "avatar_color": "#3478f6",
  "launch_url": "https://agent.example.com/app/001",
  "sort_order": 10,
  "published_at": "2026-08-24T10:00:00+08:00"
}
```

前台接口不得返回第三方密钥、后台创建人敏感信息或无展示必要的内部配置。

来源平台名称可以作为后台内部配置保留，但不属于前台展示字段，前台列表接口无需返回 `platform_name` 或来源 Logo。

服务端返回列表前必须完成：

1. 用户身份校验；
2. 发布状态过滤；
3. 有效期过滤；
4. 用户可见范围过滤；
5. 跳转地址有效性和安全状态检查；
6. 后台排序规则处理。

## 12. 权限、审计与隐私

### 12.1 权限

- 用户只能看到对自己可见且已发布的 Agent；
- 前台不得仅通过隐藏卡片实现权限控制；
- 用户直接构造 Agent ID 或跳转请求时，服务端仍需进行权限校验；
- 后台管理员权限和操作规则由后台需求另行定义。

### 12.2 审计

建议记录以下事件：

| 事件 | 建议字段 |
| --- | --- |
| 页面访问 | 用户 ID、访问时间、客户端、结果状态。 |
| Agent 点击 | 用户 ID、Agent ID、点击时间、跳转结果。 |
| 跳转拦截 | Agent ID、拦截原因、地址安全校验结果、时间。 |

审计日志不得记录第三方账号密码、Token 或用户在第三方平台中的操作内容。

### 12.3 隐私提示

页面应通过简洁文案告知用户：

- 即将离开 COMAC AI 或进入第三方平台；
- 第三方平台的隐私和数据处理规则可能与 COMAC AI 不同；
- COMAC AI 本期不会主动将当前对话或任务内容传给第三方 Agent。

## 13. 非功能要求

| 维度 | 要求 |
| --- | --- |
| 性能 | 正常网络下页面核心内容建议在 2 秒内可见。 |
| 可用性 | 单个图标或单张卡片异常不得阻断整个列表。 |
| 安全 | 跳转地址必须经过协议、域名和权限校验。 |
| 兼容性 | 支持产品当前覆盖的桌面浏览器与桌面客户端内嵌 Web。 |
| 可访问性 | 卡片操作可通过键盘聚焦和触发；图标按钮具备可读名称。 |
| 可维护性 | 前台展示内容由服务端配置驱动，不应为新增 Agent 修改前端代码。 |

## 14. 埋点建议

| 事件名 | 触发时机 | 核心参数 |
| --- | --- | --- |
| `external_agent_page_view` | 外部 Agent 页面成功展示 | 用户范围、Agent 数量、入口来源。 |
| `external_agent_card_click` | 用户点击“打开 Agent” | Agent ID、卡片位置。 |
| `external_agent_launch_success` | 前端成功发起跳转 | Agent ID、目标域名。 |
| `external_agent_launch_blocked` | 跳转被安全或配置规则阻止 | Agent ID、失败原因。 |
| `external_agent_list_error` | 列表加载失败 | 错误码、接口耗时。 |

埋点用于判断入口使用情况，不用于追踪用户在第三方平台内的具体操作。

## 15. 验收标准

### 15.1 导航验收

- [ ] 左侧存在“更多”入口；
- [ ] 点击“更多”可以展开和收起二级菜单；
- [ ] 二级菜单包含“外部 Agent”；
- [ ] 点击后右侧主区域展示外部 Agent 页面；
- [ ] 当前页面导航选中状态正确。

### 15.2 页面验收

- [ ] 页面只展示说明信息和 Agent 卡片列表；
- [ ] 页面不存在注册、创建、编辑、删除和上下架入口；
- [ ] 页面不存在“我的 Agent”区域；
- [ ] 每张卡片正确展示名称、简介和标题首字头像；
- [ ] 卡片不展示所属平台、来源名称或来源 Logo；
- [ ] 卡片不展示分类标签；
- [ ] 服务端新增或下架 Agent 后，前台无需发版即可同步展示结果；
- [ ] 空状态和加载失败状态符合本 PRD 要求。

### 15.3 跳转验收

- [ ] 点击“打开 Agent”能够打开后台配置的正确地址；
- [ ] 第三方页面在新标签页或允许的外部浏览器中打开；
- [ ] COMAC AI 原页面和当前状态不受影响；
- [ ] 非法协议、无效域名和无权限地址无法打开；
- [ ] 跳转时不携带当前对话、任务、附件和 COMAC AI 登录凭证；
- [ ] 第三方服务边界提示清晰可见。

## 16. 待确认事项

以下事项不影响展示页原型，但正式开发前需要由产品、研发、安全和业务共同确认：

1. “更多”是否仅包含外部 Agent，还是未来还会承载其他扩展能力；
2. 外部 Agent 默认在浏览器新标签页打开，还是调用桌面客户端的外部浏览器；
3. 后台可见范围是否支持全员、组织、角色和指定用户；
4. 是否需要在每次跳转前弹出二次确认，或只通过页面常驻提示告知；
5. 正式允许接入的平台和域名白名单；
6. 卡片名称、简介和头像颜色的后台字段规范；
7. 是否需要记录点击审计，以及日志保存期限；
8. 第三方平台无法访问时的责任归属和用户支持入口。

## 17. 后续演进方向

以下为可能的后续方向，不属于本期承诺：

1. Agent 数量明显增加后，再评估搜索与分类筛选；
2. 支持单点登录或受控身份联邦；
3. 支持携带经过用户确认的预设参数；
4. 通过标准 API 或 A2A 协议在 COMAC AI 内发起调用；
5. 回传运行状态、结果和输出物；
6. 建设更完整的 Agent 市场、评价、收藏和推荐能力。

任何演进都必须重新评估权限、数据传输、隐私、安全、审计和第三方服务责任边界。
