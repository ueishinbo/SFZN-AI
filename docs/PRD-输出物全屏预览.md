# PRD：输出物全屏预览

> 版本：V1.0
>
> 适用端：COMAC AI 桌面 Web / 桌面客户端内嵌 Web
>
> 关联文档：《PRD-右侧工作区与输出物预览》《PRD-Workspace工作台交互规范》

## 1. 背景与目标

当前输出物在 Workspace 内容画布中预览。并排布局下，PPT、长文档、表格或 HTML 页面可用空间有限，用户需要放大查看细节。提供当前输出物的全屏预览，让用户在不离开当前任务的情况下阅读、演示和检查内容，并能一键返回原工作现场。

本需求中的“全屏”指预览层占满应用可用视口，隐藏对话区、文件导航、输出物浮层及 Workspace 标签栏；不要求浏览器或操作系统进入原生全屏。“缩放”指在预览层内调整文件内容比例，两者是独立操作。

## 2. 适用范围

- 入口仅出现在已成功打开、可预览的输出物工作视图中，包括 PPT、Word、Markdown、JSON、文本及受控 HTML Browser；普通任务与助理模式行为一致。
- 普通附件、记忆文件、任务投影及启动器不在本期范围；不可预览、无权限、已过期的输出物不显示可用的全屏入口。
- 本期只读，不增加编辑、批注、演讲者模式或跨文件轮播。

## 3. 入口与页面结构

1. 在当前输出物的二级上下文栏右侧提供“全屏预览”图标按钮，Tooltip 和无障碍名称均为“全屏预览”。HTML Browser 的入口与其他输出物保持同一位置，避免出现两个全屏按钮。
2. 点击后直接进入全屏预览，不弹确认框；保留当前文件、版本、PPT 页码、文档滚动位置及已设置的内容缩放比例。
3. 全屏层顶部固定精简工具栏：左侧为文件名（超长截断并可悬停查看全名），右侧为文件适用的页码/缩放控件、下载入口及“退出全屏”图标按钮。下载权限与普通预览一致。
4. 内容区使用剩余空间居中展示文件，不裁切内容；超出可视区时在内容区内部滚动。PPT 缩略图可收起，默认保留当前页主画布优先。HTML 保留原有沙箱限制及页面交互能力。
5. 全屏状态下隐藏 Workspace 文件导航、输出物浮层、标签栏和对话区，不允许通过底层控件误触切换文件；不新增浏览器历史记录或独立标签。

## 4. 交互规则

| 场景 | 预期行为 |
| --- | --- |
| 进入 | 点击“全屏预览”后，当前输出物内容在全屏层继续展示；加载中的预览保持加载态，不重新生成文件。焦点移至全屏工具栏。 |
| 退出 | 点击“退出全屏”或按 `Esc`，关闭全屏层并返回进入前的 Workspace：同一标签、文件、页码、缩放及滚动位置；焦点返回原全屏按钮。 |
| 页面/内容操作 | PPT 翻页、文档滚动、HTML 内部交互仅更新当前输出物状态；退出后继续保留。全屏内不提供切换其他输出物的入口。 |
| 缩放 | 对支持缩放的静态预览提供“适应页面/适应宽度”、放大、缩小及百分比显示；默认沿用进入前比例，首次打开为“适应页面”。缩放范围 50%–200%，步进 25%；达到边界时对应按钮禁用。HTML 使用页面自身响应式布局，本期不提供宿主缩放。 |
| 窗口变化 | 浏览器尺寸改变时重新计算“适应”比例；用户手动设置的百分比保持不变。始终不出现页面级横向滚动。 |
| 浏览器返回 | 若应用已有返回行为，退出全屏后执行原有返回逻辑；全屏本身不占用浏览器历史层级。 |

## 5. 状态与边界

- 全屏中预览加载或转换失败：留在全屏层，展示明确错误、重试入口及可用时的下载入口；退出仍返回原标签。
- 全屏中权限被撤销、文件过期或版本失效：停止展示受保护内容，说明原因；不自动切换到其他文件。重新获得权限或刷新后按现有预览规则恢复。
- 网络断开：已加载内容可继续阅读时保留；需要网络的后续页或资源显示离线提示和重试，不显示空白画布。
- 文件在全屏期间产生新版本：当前预览维持原版本并提示“有新版本”，用户主动刷新后才切换；避免阅读中内容跳变。
- 关闭当前 Workspace 标签、切换 Session/助理模式、登出或直接打开另一个输出物时，先退出全屏，再按原动作继续；不得让旧文件覆盖新上下文。
- 打开全屏前已有的文件导航/输出物浮层状态在退出后恢复；全屏期间不接受底层点击。若原标签因权限变化不可访问，退出后保留标签并显示对应错误态。
- 不支持浏览器原生全屏的环境仍可使用应用视口全屏。移动端沿用单页 Workspace：工具栏仅保留退出、必要页码和缩放入口；控件不遮挡内容，滚动范围局限于预览区。

## 6. 验收标准

1. 从普通任务和助理的可预览输出物均可进入和退出全屏；两种模式入口位置和操作一致。
2. 进入前后文件、PPT 页码、文档滚动位置和手动缩放比例一致；重复进入退出不产生重复标签或重新生成输出物。
3. `Esc` 和退出按钮均可关闭全屏，键盘焦点回到入口；工具栏按钮有 Tooltip、可访问名称和明确禁用态。
4. 50% 与 200% 边界、适应页面/宽度、窗口尺寸变化均表现正确；内容不被裁切，页面不产生横向滚动。
5. 加载失败、无权限、已过期、离线和新版本状态有可理解反馈；退出全屏不丢失原 Workspace 状态。
6. HTML 全屏后仍处于原受控沙箱，不获得新的宿主权限或任意网址访问能力。
