## 1. 背景与目标

领导近期有演讲需求，需要通过产品页面辅助讲解系统智能与个人数字分身的应用形态。当前时间不足以完成正式产品的完整开发评审及建设，因此本期先上线限定账号可见的演示版本。

领导知晓这是 Demo，演示以口述、浏览和少量点击为主。页面需要具备真实产品的结构和自然交互，但任务执行、数字分身运行、岗位能力及协作记录可以使用预置数据和受控模拟。

交付目标：

1. 能从任务模式进入系统智能，查看项目、任务状态及既有 A2A 协作记录。
2. 能进入领导个人数字分身，讲解身份、工作理解、岗位能力和成长过程。
3. 主要入口可点击，返回路径完整，重复演示可恢复到统一初始状态。
4. 仅领导指定账号获得新增功能，其他用户原有产品体验不受影响。

本期不以真实智能体运行效果、业务任务完成率或模型评测成绩作为验收指标。

## 2. 决策状态与范围原则

### 2.1 已确认

- 本期仅覆盖任务模式「系统智能」和个人「数字分身」相关演示页面。
- 只对领导一个指定账号上线新增功能。
- 岗位智能体等内容可以模拟，演示不要求真实业务执行。
- 系统智能首页去掉英文 SYSTEM INTELLIGENCE，使用通用介绍文案。
- 默认项目为 IPT、供应链；供应链沿用现有示例。
- IPT 有两个任务：待开始「完成工程总体办年度任务（2026）」、进行中「完成26年生产链式智能建设」。前者进入后内容为空，后者展示模拟 A2A 对话。
- A2A 对话包含陈帅、刘娟等参与人，具体记录后续替换。
- 系统智能首页提供模拟添加项目入口。
- 专家、技能、MCP 列表不展示版本及详情按钮；不展示 MCP 申请权限、待授权、审批中等流程。

### 2.2 首版建议，供本期开发估算

以下为本稿提出的实施基线，尚不是需求方已确认的产品决策：数字分身二级页面范围、模拟交互的保存方式、A2A 附加操作收敛方式、演示恢复机制、性能目标。开发可据此估算，范围冻结时逐项确认。

现有原型中出现某个按钮，不代表其完整业务流程自动纳入本期。只实现本文件约定的展示与交互；其他历史 PRD 不自动扩大本期工作量。

## 4. 账号与发布要求

### 4.1 指定账号开放

- 以现有登录体系返回的稳定用户 ID 配置唯一演示账号，不能用显示姓名判断。
- 使用「总开关 + 指定账号」共同控制；总开关关闭或账号不匹配时，新增入口均不展示。
- 除导航隐藏外，直接地址、页面参数、收藏链接及恢复旧页面状态也必须做访问判断；非演示账号回到现有默认页。
- 如提供演示专用接口，由服务端进行同样的账号校验；不得仅依赖前端隐藏。
- 演示数据与正式业务数据独立存储。身份判断失败时默认不开放，不显示领导演示内容。
- 如采用静态 Mock 包，普通用户不应通过演示入口或专用数据接口加载该数据；敏感演示素材不能作为全员可下载的公共静态资源发布。

### 4.2 发布与退出

复用现有登录与部署方式，不新增登录产品。开发交付开关配置说明、账号配置位置、演示数据版本和回退方法。演讲结束后可关闭开关撤回新增入口，无需影响原有产品。

待补充：领导账号 ID、部署地址、发布与演讲时间、开关负责人、演示后保留时长。

## 6. 系统智能页面与交互

### 6.1 首页

标题「系统智能」；介绍「围绕共同目标，统筹任务推进与跨团队协作。」；右上角「添加项目」。项目区域副文案「进入项目查看任务，跟进数字分身的协作进展。」

默认按 IPT、供应链顺序展示，仅这两个预置项目。卡片包含名称、简短描述、图标、进入箭头，不新增复杂业务指标。

| 操作 | 行为 | 边界 |
| --- | --- | --- |
| 点击项目卡 | 进入对应项目，默认计划视图 | 整张卡片可点击 |
| 搜索项目 | 按名称和描述进行本地包含匹配 | 去除前后空格；清空恢复全部；无结果显示明确提示 |
| 添加项目 | 弹窗填写名称、描述 | 名称必填，最多40字；描述选填，建议最多200字 |
| 确认添加 | 关闭弹窗，清空搜索，新增卡片 | 新项目内没有任务；不创建真实项目 |
| 名称为空 | 添加按钮禁用 | 纯空格视为空值 |
| 重复名称 | 提示「项目名称已存在」 | 首版建议避免演示重复卡片 |
| 取消或关闭 | 关闭弹窗，不新增 | 再次打开使用空表单 |

新增项目只在当前页面会话中保留，刷新恢复默认项目，不提供编辑、删除、新建任务等扩展流程。

### 6.2 项目详情

顶部包含返回系统智能、项目名称与说明。保留「计划」「任务」两个视图。

- 计划视图：待开始、进行中、已完成三列，列标题展示对应任务数。
- 卡片：名称、可选目标摘要、负责人、计划完成时间、优先级与进入标识。
- 任务视图：同一批任务以列表展示名称、状态、负责人、完成时间。
- 切换视图不改变任务状态；不实现拖拽、任务编辑或任务删除。
- 空列显示「暂无对应状态任务」；新建空项目的任务列表显示「暂无任务」。

IPT 初始数据：

| 名称 | 状态 | 点击结果 |
| --- | --- | --- |
| 完成工程总体办年度任务（2026） | 待开始 | 打开空白任务内容页 |
| 完成26年生产链式智能建设 | 进行中 | 打开预置 A2A 协作记录 |

已完成列数量为0。年度任务正文不放自动生成说明、消息、启动确认卡或输入框；仅保留页面标题和返回 IPT 导航。负责人、日期、优先级是待替换占位数据，不能当作真实业务承诺。

### 6.3 A2A 协作记录

复用现有 A2A 会话展示结构，中央展示正式历史记录；如保留右侧私人分身区域，明确其只属于当前用户。进入会话后有明确的返回任务模式入口，返回后恢复 IPT 项目现场。

- 参与人至少包含陈帅、刘娟；当前第三人为王磊，占位待替换。
- 显示任务名称、目标、参与人姓名、数字分身身份、时间与按序排列的消息。
- 内容形成承接关系：陈帅提出建设范围和分工 → 刘娟补充生产场景 → 王磊提出数据衔接及联调安排。
- 进入页面即展示完整既有记录，不逐条现场生成，不显示无限等待或要求他人上线。
- 历史意见已收齐不等于整个建设任务已完成；主路径返回看板后仍在进行中。
- 首版建议将该会话作为历史浏览页：隐藏「确认完成」「继续核对」、新增群聊、真实发送等非必要动作，避免误点改变演示主线。
- 如必须保留私人输入框，提交后仅在私人区域显示统一反馈「已记录你的补充意见」，不追加虚构他人回复、不发消息、不修改看板状态。

供应链保留现有三个任务及示例内容：替代紧固件齐套确认（待开始）、关键供应商交付延期处置（进行中）、到货批次证书补齐（已完成）。原有查看方式沿用，演示版同样不触发真实发送、审批或业务更新。

## 7. 个人数字分身页面与交互

以下二级范围为基于当前原型提出的首版建议，待需求方与演讲脚本一起冻结。当前入口文案为「训练数字分身」，本稿统称个人数字分身模块；暂不要求新增入口或重命名。

### 7.1 首页与身份

保留当前模块顺序：身份 → 用户心智 → 岗位智能体 → 能力 → 分身评测 → 成长曲线 → 对话日志。

- 标题为「{领导姓名}的数字分身」，岗位、部门与身份弹窗保持一致。
- 点击「身份信息」查看姓名、工号、岗位、部门、组织、小组等预置字段，不提供身份编辑。
- 当前原型中的张三、解决方案经理等信息仅为占位，不直接作为领导身份上线。
- 页面内弹窗关闭后恢复原滚动位置；返回任务模式不丢失原项目浏览位置。

### 7.2 用户心智

| 入口 | 默认展示 | 可演示交互 |
| --- | --- | --- |
| 工作画像 | 已形成的工作定位、关注重点、沟通偏好、判断习惯、确认边界 | 默认可直接查看；更新时沿用分步表单，生成确定性预览，确认后仅本地应用 |
| 目标 | 预置目标、统计口径、验收标准 | 查看；如保留编辑，保存后本地更新，取消不变 |

不要求现场先完成问卷才能看到画像。不接真实文档提炼、模型生成或组织画像同步。画像更新中的材料环节只选择预置材料或跳过，真实上传解析不纳入本期。

未保存内容关闭时提示是否放弃；画像与目标保存只改变演示副本。主路径不要求新增成长事件；本期无需完善跨模块自动联动。

### 7.3 岗位智能体

- 首屏预置已挂载的岗位智能体卡片，名称、目标与领导角色相匹配，清单后续提供。
- 卡片保留启停与查看；岗位版本如沿用当前卡片展示，使用固定占位值。本次去版本要求针对专家、技能、MCP，不自动扩展到岗位智能体。
- 查看弹窗展示岗位职责、工作边界、需要人工确认的情况及可用能力；有内容时再展示能力地图、知识地图、输出模板。
- 不展示后台草稿、审批、发布按钮，不要求开发真实岗位挂载服务。
- 启停只改变模拟状态和对应可用能力统计，不触发 Agent 运行。
- 复用现有能力去重规则：相同资源按 ID 只计一次；岗位停用不得移除仍由其他启用岗位或个人配置保留的能力。
- 本期不新增岗位添加、移除及后台配置路径，以当前预置岗位浏览为主。

### 7.4 能力：专家、技能、MCP

三个页签共用轻量列表：名称、描述、状态、一个启停或连接操作。MCP 可保留工具数量；三个列表及添加候选列表都不显示版本和详情按钮。

| 操作 | 结果 |
| --- | --- |
| 切换页签 | 展示对应类别，搜索与状态筛选重置 |
| 搜索/状态筛选 | 本地筛选；无结果给出空提示 |
| 添加 | 弹窗勾选预置候选项，确认后加入列表；无选择时不能确认 |
| 重复添加 | 已添加资源不再出现在候选项中 |
| 启用/停用 | 状态与可用数量同步更新 |
| MCP连接/断开 | 仅切换模拟连接状态，不请求实际服务 |

不出现「待授权」「申请权限」「审批中」及详情入口。首版建议主讲资源均预置为可用；如沿用不可用项，统一显示「暂不可用」并禁用操作，不引导申请。

### 7.5 知识库

展示预置知识条目与知识关系示意，支持已有搜索、分类及条目预览。知识正文由 Mock 提供，不连接真实知识平台。

首版将知识库作为只读讲解页，不纳入真实文件上传、解析、索引、外链访问和删除。现有原型相关操作应在演示版隐藏，避免出现无定义流程。

### 7.6 分身评测

复用现有评测概览与详情版式，以预置数据展示配置准备度、能力覆盖及已有评测记录。图表、数量、详情使用同一份数据。

- 点击概览或查看详情打开对应内容，关闭返回原位置。
- 不运行真实模型评测，不产生新的正式分数或认证结论。
- 首版不开放重新评测、训练及后台复核入口。
- 分值、维度和结论为待确认素材；具体口径随最终 Mock 一起确认，不能解释为领导个人绩效。

### 7.7 成长曲线与对话日志

成长曲线保留日/周/月切换、日期选择、周期前后切换及事件详情。默认定位到有预置事件的日期，避免演讲当天自动落到空白。

事件至少覆盖画像更新、岗位或能力配置、知识补充等类别；标题、时间、摘要、详情互相一致。无事件时正常显示空状态。对话日志只浏览预置记录与详情，不读取真实领导聊天历史，不提供真实重放或重新执行。

## 8. Mock 数据、状态与恢复

### 8.1 统一数据原则

- 将文案、项目、任务、身份、岗位、能力、记录集中维护，禁止在多个页面分别硬编码同一人员信息。
- 所有实体有稳定 ID；项目、任务、会话的引用必须可校验。
- 任务状态、协作展示状态分别管理；不能因“已回复”推导业务任务已完成。
- 默认数据是可恢复基线，用户操作修改的是演示副本。
- 默认不展示开发用脚本名、接口名或 Mock 控制按钮；演示性质在交付说明中明确。

### 8.2 首版建议的保存规则

| 数据 | 当前浏览过程中 | 刷新或重新进入演示会话后 |
| --- | --- | --- |
| 预置项目、任务、A2A历史 | 固定展示 | 恢复原始基线 |
| 添加的项目 | 暂存当前页面会话 | 清除，仅剩 IPT、供应链 |
| 能力启停、个人添加、画像修改 | 暂存演示会话 | 恢复原始基线 |
| 搜索、弹窗、视图选择 | 正常操作与返回时保留必要现场 | 恢复默认 |
| 主讲解身份、成长日期 | 使用同版配置 | 保持冻结值，不随系统日期漂移 |

开发可用内存或独立会话存储实现，不沿用正式账号个人设置的存储键。若复用当前原型的持久化 Store，需要增加演示隔离层，不能把旧原型数据覆盖行为当作已实现的刷新恢复。

### 8.3 恢复与异常

提供演示保障人员使用的恢复方法（配置操作或专用维护入口即可），一次恢复本 Demo 的配置副本、新增项目、输入和浏览状态，不清理正式用户数据或整个站点存储。

重复点击不重复添加或堆积相同对话；无效任务 ID 提示「任务不存在」并允许返回；缺少可选内容省略该区块，缺少关键数据时阻止进入损坏详情并提供返回。依赖的字体、图标、图片随应用部署，主路径不加载第三方远程素材。
