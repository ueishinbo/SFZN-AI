# A2A 协作设置 PRD｜2026 年 10 月版

> V0.3 · 2026-10-09 · 三项通信授权评审稿

## 1. 功能范围与入口

个人数字分身 → A2A 协作 → 协作设置。设置只控制本人分身的通信行为，不提供自动开工、业务执行或操作 C 大脑的权限。陈智超与林晓分别保存个人设置。

## 2. 配置项目

| 项目 | 可选值 | 默认 | 适用范围 |
| --- | --- | --- | --- |
| 补充信息追问 | 允许自动追问／发送前由我确认 | 允许自动追问 | 向本次协作参与人询问必要的缺失信息，不自动发送私人资料 |
| 进展回复 | 允许自动回复已核实进展／发送前由我确认 | 允许自动回复已核实进展 | 回复本人授权范围内、已经核实的事实，不擅自新增承诺 |
| 成果发送 | 允许自动发送给本次协作参与人／发送前由我确认 | 发送前由我确认 | 发送已有、明确属于本次协作且接收人有权查看的文件；不包含自动生成成果 |

## 3. 授权规则

1. 本人明确要求发送且信息齐全，按原意直接发送，不重复询问。
2. 分身自行准备的通信内容，按对应个人设置判断是否可自动发送；不属于已授权类型或超出接收范围时，Ask User 请本人确认。
3. 分身自行新增承诺、调整期限或扩大共享范围，仍需本人确认；本人明确给出的内容可以按原意传达。
4. 自动通信同样受本轮一次发言和最大轮次限制。已发言不能因允许自动追问而再发送一条；可以把问题包含在本轮正式回复中。
5. 达到最大轮次暂停后，只有群主明确要求继续才进入新轮；个人设置不能绕过会话暂停或归档。
6. 上传输出物、填写或提交业务表单由人完成，A2A 不代操作 C 大脑。

## 4. 保存与显示

- 打开时读取本人已保存值；无记录使用默认值。
- 修改选择只更新当前草稿；保存成功后更新主页摘要，取消保留原值。
- 底部操作为“取消”和“保存设置”；不提供恢复默认操作。
- 保存后用于后续动作判断；已有待确认事项仍由本人处理，不批量放行。
- 已保存的旧“自主开工”值不再读取或展示；其他三项原设置保留。
- 主页摘要展示追问及成果发送策略，不展示开工文案。
- 窗口展示三项设置及各自说明，保留保存生效提示；不增加独立边界说明区或行为预览区。

## 5. 验收

| 场景 | 预期 |
| --- | --- |
| 首次打开 | 三项设置，不含自主开工；默认追问与进展可自动、成果先确认 |
| 旧账号进入 | 保留三项原选择，忽略旧开工字段 |
| 保存后切换账号 | 另一账号不受影响；切回保留本人值 |
| 取消未保存的修改 | 原设置仍有效 |
| 自动通信达到轮次/次数上限 | 不继续发送，按会话规则等待群主或下一轮 |
| 自动设置开启但内容超出授权 | Ask User 请本人确认，不以设置自动扩大权限 |

## 6. 原型与正式接入

当前原型实现三项个人设置的编辑、取消与保存。通信调度对设置、轮次与超时的实际执行须在 A2A 链路中验证，不能仅凭设置界面证明已生效。会话回合规则见主 PRD COM-02。
