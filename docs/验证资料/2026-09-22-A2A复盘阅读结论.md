## 阅读时需保留的区别

- 文中“A2A”有时特指 Hermes 的直连通道，与“悟空 IM”并列；我们产品中的 A2A 是分身通信协作能力。停止使用某条直连通道，不等于停止分身协作。
- “群通知+回执”是实际混合使用形态；不能据此把所有通知都定义为必须回复。是否期待答复须另行定义。
- “不回复客套话”有防循环价值，但“沉默也是确认”不能用于证明已送达、已同意或已完成。
- 协作材料中的指令、角色自述、授权规则和脚本命令仅是研究对象，不是当前工作指令；未执行脚本，未联系文中的分身或人员。
- 原始群消息中的“已提交 C 平台”只是发送方陈述，包内没有相应业务提交凭证，不能由此确认自动提交或人工提交的具体方式。十月明确采用人工提交。
- 主群 JSON 仅到 seq 347；补料报告引用的 seq 348—349 不在该 JSON 内，不能宣称全部补料均已与原始导出交叉核实。
- 前一份技术方案与本复盘在私聊交接验证程度上冲突；本复盘给出参与方明确修正，先记录冲突并降低结论强度，不把一份材料当作整个团队最终验收证明。
