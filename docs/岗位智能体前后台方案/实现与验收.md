# 岗位智能体 Demo：实现与验收

更新：2026-09-08

## 运行

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

- 个人数字分身：`http://127.0.0.1:5174/SFZN-AI/?view=twin`
- 岗位管理：`http://127.0.0.1:5174/SFZN-AI/?view=admin`
- 审批中心：`http://127.0.0.1:5174/SFZN-AI/?view=admin&page=approvals`
- 运行治理：`http://127.0.0.1:5174/SFZN-AI/?view=admin&page=logs`

## 已实现

| 模块 | 行为 |
| --- | --- |
| 岗位管理 | 具体岗位卡片、搜索、状态与可添加范围筛选、新建、复制、删除未发布草稿、单页锚点详情 |
| 岗位定义 | Markdown 编辑与预览、结构摘要、Word/PDF/Markdown 导入、原文件保留与下载 |
| 能力与资产 | 引用技能、MCP、专家及模型；增改删 SOP、模板及红线用例；检测失效引用 |
| 生效范围 | 组织、小组、指定人员按或关系匹配；父组织包含子组织；仅发布范围影响个人资格 |
| 评测发布 | 草稿、规则与用例检查、人工复核、独立审批、发布；支持撤回、驳回、停用、恢复与回滚 |
| 审计 | 评测历史、发布版本、变更比较、审批依据、操作记录及导出 |
| 个人岗位 | 主动添加、独立启停、确认移除、只读岗位说明；不可编辑组织定义 |
| 个人能力 | 按资源 ID 合并和去重；保留个人及其他岗位的共享引用；受限资源须单独申请权限 |
| 私有知识 | 独立知识清单、原有知识地图、个人资料新增/编辑/导入/下载、启停与删除确认 |
| 个人评测 | 六类画像的结构与内容完整度检查；按实际个人评价汇总有帮助比例；保存并下载评测快照 |
| 运行治理 | 个人完整记录与后台脱敏投影分开呈现；岗位/版本/反馈/归因/范围/日期筛选；导出有审计 |
| 受控进化 | 90 天热力日历、重复问题信号、建议证据、采纳落到草稿、拒绝留理由；评测审批后生效 |
| 交互保护 | 保存失败提示、未保存离开确认、身份切换保护、只读和权限门槛、空状态与窄屏布局 |

个人画像、成长记录和 A2A 会话入口继续保留。后台岗位配置不包含知识库配置，也不直接替用户绑定岗位。

## 体验流程

1. 后台以“赵敏 · 资源管理员”创建或修改岗位，保存正文、能力、资产和范围。
2. 发起评测，检查证据，填写人工复核结论后提交审批。提交人和维护人不能审批自己的版本。
3. 切换“李明 · 审批人”，从审批中心查看发布影响、用例和复核意见，再批准或驳回。
4. 个人端添加已发布且在本人范围内的岗位，观察启停与共享能力变化。权限申请也进入审批中心。
5. 使用“准备工作任务”按启用岗位的 SOP 和模板生成执行预案，记录当时的岗位版本与能力快照，然后评价结果。
6. 后台查看脱敏记录及进化建议。采纳只修改草稿，不会直接改动线上版本。
7. “陈曦 · 平台管理员”可验证岗位停用、恢复及历史版本回滚。

## 验收

- `npm test`：17 个业务场景，覆盖范围匹配、共享能力、权限审批、发布状态流转、独立审批、资源失效、建议处理、脱敏、反馈阈值、持久化、版本递增和评测历史。
- `npm run lint`：静态检查。
- `npm run build`：TypeScript 与生产构建。
- 浏览器实际验证：建议采纳 → 评测 → 复核 → 独立审批 → 个人端版本更新；多岗位添加和启停；能力去重与待授权连接；任务预案、反馈及评测保存后刷新；Word/PDF/Markdown 导入；草稿离开保护；全岗位版本筛选与脱敏详情；新增个人知识；页面横向溢出修复。

## 数据和接入边界

这是可交互的浏览器 Demo。主业务数据保存在当前浏览器的 `comac-role-center-v3`，个人知识和个人评测分别独立保存。保留已有个人画像存储。不同浏览器、来源和端口的数据不会自动共享；同一来源支持标签页同步。

工作身份切换用于演示权限流程，并不构成服务端身份认证。模型、MCP、企业组织服务及真实消息发送尚未接入；“试运行”和“准备工作任务”根据已配置 SOP/模板生成执行预案，不伪造业务查询结果。岗位评测为规则校验与人工复核，个人评测为配置完整度及用户反馈统计。

生产接入时须将身份、权限校验、持久化、审计与脱敏投影迁移至服务端，再接模型执行、业务连接和评测服务。当前代码中的治理投影仅用于 Demo 的展示边界，不是服务端隔离。
