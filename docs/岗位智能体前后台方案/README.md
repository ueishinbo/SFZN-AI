## 当前已确认口径

1. 产品统一称为“岗位智能体”，不引入“实例”概念；
2. 后台直接管理具体岗位智能体，例如功能型产品经理智能体，不设岗位大类和二级方向；
3. 后台按组织、小组、指定用户决定可添加范围；个人命中范围后，在前台主动添加到自己的数字分身；
4. 一人可添加多个岗位智能体，并可独立启用、停用或移除；岗位智能体在个人前台是独立一级模块，位于“能力”模块上方；
5. 个人可自行管理专家、技能、MCP、知识库等现有模块；岗位智能体配置的能力进入同一能力集合，按资源 ID 去重，前台暂不标记来源、不做冲突处理；
6. 知识库仍由个人维护，仅影响本人；个人完整对话默认不暴露后台；
7. 岗位评测与发布、运行治理和受控进化已在当前前端 Demo 中实现；真实身份、组织、权限、持久化、审计、模型和业务服务仍未接入。
