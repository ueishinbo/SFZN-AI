## 1. 文档目的

本文定义普通任务模式与助理模式共用的 Workspace 结构、文件定位、输出物预览、响应式切换、状态保持和正式服务边界。

V2.1 的核心变化是：**普通任务与助理必须复用同一个 Workspace 工作台和同一套交互，不再分别维护“输出物抽屉”和“助理文件面板”。**两种模式只改变根目录、文件内容和默认选中项，不改变工作台骨架。标签、输出物浮层、右侧导航和 Browser 的精确状态机以《PRD-Workspace工作台交互规范》为准。

本文描述正式产品行为。当前 Demo 可使用 Mock 数据和前端状态验证交互，但不得将浏览器本地状态、固定日期或关键词剧本作为正式实现方案。

## 2. 背景与问题

上一版普通任务的右侧区域以“模块菜单 + 多文件页签 + 浏览器/变更入口”为主，助理模式则以“文件树 + 文件预览”为主。两套结构造成三个问题：

1. 用户在普通任务中生成 PPT，右侧区域的布局和操作与助理中查看文件不同，需要重新学习；
2. 旧版“模块菜单、变更、无边界文件页签”暴露了过多工具概念，右侧区域逐渐像信息化后台，而不是对话的工作台；
3. 两套组件会在视觉、响应式、预览能力和后续功能上持续分叉，研发维护成本高。

因此本期统一为一个轻量 Workspace 工作台：顶部标签承载当前工作视图，输出物浮层负责快速打开生成物，右侧文件导航按需展开，内容画布负责文件预览或受控 HTML Browser。

## 3. 产品目标

1. 用户在普通任务和助理之间切换时，不需要重新理解右侧区域。
2. 用户点击聊天中的输出物卡片后，一步打开 Workspace、定位文件并预览。
3. 用户主动打开 Workspace 时，可以理解文件落在什么目录，而不是只看到孤立的输出物列表。
4. 普通任务只暴露当前 Session 目录；助理只默认暴露 Assistant 目录，避免上下文和权限污染。
5. 宽屏、中等窗口和移动端都保持可用，不通过无限压缩维持双栏。
6. 为后续真实 Workspace、Artifact、Memory 和 A2A 服务预留稳定对象和状态接口。

## 4. 非目标

本期不做：

- 在线编辑 Office、Markdown 或 HTML；
- 在 Workspace 内创建、移动、重命名、删除文件；
- 无限制堆叠、拖拽排序和跨 Session 混用的旧式文件页签；
- 通用互联网浏览器和用户手动输入网址；
- 独立“变更”模块入口；
- 独立“待我处理 / 我发起的”协作面板；
- 自动化任务运行结果预览；
- 多人实时共同编辑；
- 将逻辑目录等同于底层物理存储路径。

HTML 输出物默认在受控 Browser 工作视图中运行，同时允许打开源文件标签。Browser 只允许打开用户自己生成的 HTML，不允许输入网址。

## 5. 核心原则

1. **一套组件**：普通任务和助理共用同一个 Workspace 工作台、顶部标签、输出物浮层、右侧文件导航、内容画布和响应式规则。
2. **模式决定根目录**：普通任务定位当前 Session，助理定位 `Assistant/`。
3. **对话负责意图，Workspace 负责文件**：生成、查询、派发、催办在对话发生；定位和预览在 Workspace 发生。
4. **生成不打断**：输出物生成完成后先在聊天中展示卡片，不自动弹开 Workspace。
5. **点击即定位**：点击卡片必须打开 Workspace、展开祖先目录、选中文件并显示预览。
6. **单视图焦点**：允许打开多个去重的文件或 Browser 标签，但同一时刻只有一个激活工作视图。
7. **文件视图不是事实源**：A2A 任务文件、记忆文件和输出物均可以是服务对象的逻辑投影。

## 6. 术语

| 术语 | 定义 |
| --- | --- |
| Workspace | 统一工作台，包含工作视图标签、输出物浮层、右侧文件导航和内容画布。 |
| Workspace 根目录 | 当前模式允许展示的最高层逻辑目录。 |
| 当前 Session | 用户当前打开的普通任务会话。 |
| Assistant 目录 | 个人助理专属目录，包含规则、记忆、协作投影和助理输出物。 |
| Artifact | 智能体生成、可预览或下载的文件对象。 |
| 输出物卡片 | 助手消息中展示文件名、类型、大小并可打开文件的入口。 |
| 选中文件 | 当前在文件树中高亮且在内容区预览的唯一文件。 |
| 文件投影 | 将结构化对象转换为用户和 Agent 可读文件的视图，不是唯一事实源。 |

## 7. 模式与目录

### 7.1 普通任务模式

普通任务 Workspace 只展示当前 Session：

```text
/Workspace/Tasks/YYYY-MM-DD/{task-session-id}-{safe-title}/
├── context.md
├── attachments/
└── outputs/
    └── {artifact-file}
```

规则：

- `YYYY-MM-DD` 是 Session 创建日期；跨天继续对话不移动目录；
- `context.md` 展示任务目标、约束、关键决策和待办摘要；
- 用户上传或受控引用的文件进入 `attachments/`；
- 当前 Session 生成的文件进入 `outputs/`；
- 一个 Session 的文件不得自动出现在另一个 Session；
- 标题变化可改变展示名，但关联始终依赖稳定 `task_session_id`。

### 7.2 助理模式

助理 Workspace 默认只展示 Assistant 目录：

```text
/Workspace/Assistant/
├── SOUL.md
├── AGENT.md
├── USER.md
├── MEMORY.md
├── memory/
│   └── YYYY-MM-DD.md
├── collaboration/
│   ├── index.md
│   └── tasks/
│       └── {collaboration-task-id}.json
└── outputs/
    └── YYYY-MM-DD/
        └── {artifact-file}
```

规则：

- 每个用户只有一个逻辑助理长 Session；
- 每日记忆是长 Session 的时间切片，不是新的 Session；
- A2A 任务查询结果在聊天中出现，点击后定位到对应任务投影文件；
- Assistant Workspace 默认不展示全部普通任务；
- 助理按需检索普通任务时，可临时打开授权文件，但不改变默认根目录和归属关系。

### 7.3 两种模式的统一与差异

| 维度 | 普通任务 | 助理 |
| --- | --- | --- |
| 组件 | 统一 Workspace | 统一 Workspace |
| 标题 | Workspace | Workspace |
| 左侧 | 当前 Session 文件树 | Assistant 文件树 |
| 右侧 | 当前选中文件预览 | 当前选中文件预览 |
| 文件头 | 名称、大小、更新时间、路径、文件操作 | 同左 |
| 默认根目录 | 当前任务 Session | `Assistant/` |
| 默认选择 | 上次选择；无记录时 `context.md` | 上次选择；无记录时 `MEMORY.md` |
| 特有内容 | 附件、当前任务输出物 | 规则、记忆、协作投影、助理输出物 |

任何只因模式不同而产生的视觉结构、按钮位置和手势差异，都应视为设计缺陷，除非对应能力在该模式明确不可用。

## 8. Workspace 界面结构

### 8.1 双层工作台导航

一级顶栏左侧为工作视图标签和 `+` 启动器，右侧固定保留两个按钮：

1. 输出物；
2. Workspace。

二级上下文栏展示当前逻辑路径、文件操作和独立的文件夹目录按钮。一级 Workspace 按钮只隐藏或恢复整个工作台；二级文件夹按钮只开关目录。两者不得根据状态互换语义。

不提供底部面板、终端、来源和侧边任务。打开与关闭使用各自相同位置的按钮，文件导航内部不再放第二个关闭按钮。

### 8.2 工作视图标签

- 文件标签用于 PPT、Word、Markdown、JSON、文本和 HTML 源文件；
- Browser 标签用于运行自己生成的 HTML；
- 相同对象重复打开时聚焦已有标签；
- 关闭激活标签后选择相邻标签；
- 关闭最后标签时退出 Workspace，同时关闭输出物浮层和右侧导航；
- 点击 Workspace 按钮暂时隐藏时保留标签、激活标签和目录开关状态，恢复后回到原工作现场；
- 没有标签时打开 Workspace 进入启动器，不自动创建默认文件标签；
- 标签状态与当前 Session 隔离。

完整规则以《PRD-Workspace工作台交互规范》第 6 章为准。

### 8.3 输出物浮层

- 从顶部输出物按钮展开；
- 普通任务只展示当前 Session 输出物；
- 助理只展示 Assistant 输出物；
- 一期不展示来源；
- HTML 默认打开 Browser，其他支持类型打开文件标签；
- 浮层是临时层，不成为常驻第三栏。

### 8.4 右侧文件导航

- 包含文件筛选、逻辑根路径和文件树；
- 文件夹支持展开和收起；
- 选中文件有明确高亮；
- 文件树只展示当前用户有权访问的节点；
- 从文件树点击 HTML 时打开源文件标签，不替代 Browser 运行视图；
- 文件较多时内部滚动，不引起页面级滚动；
- 关闭右侧导航不关闭标签，也不退出 Workspace。

### 8.5 内容画布与上下文栏

当前激活标签独占内容画布。文件名和类型位于一级标签；大小、更新时间、逻辑路径、下载和目录开关位于二级上下文栏，不再重复展示独立文件标题行。Browser 标签展示只读地址、刷新、前进后退状态、查看源文件和受控 HTML 运行结果。

文件操作必须基于稳定 `node_id` 或 `artifact_id`，不得仅依赖文件名或路径。加载、转换、失败、无权限和已过期必须有明确状态。

## 9. 输出物生成与打开流程

### 9.1 生成成功

1. 用户在普通任务或助理对话中提出生成文件的需求；
2. 服务端创建 Artifact，完成存储和预览准备；
3. Artifact 关联当前 Session、来源消息和 Workspace 节点；
4. 文件节点出现在对应 `outputs/`；
5. 助手消息展示输出物卡片；
6. Workspace 不自动打开，用户可继续对话。

输出物卡片至少展示：文件名、文件类型、文件大小。可以补充生成状态，但不承载完整文件管理功能。

### 9.2 点击输出物卡片

点击卡片后必须原子地完成：

1. 校验文件当前可访问；
2. 打开 Workspace；
3. 切换到当前模式的根目录；
4. 展开文件的祖先目录；
5. 选中对应文件节点；
6. 滚动文件树使节点可见；
7. HTML 打开或聚焦 Browser 标签，其他类型打开或聚焦文件标签；
8. 展示对应内容画布。

重复点击同一卡片不会创建重复标签，只重新聚焦同一工作视图。

### 9.3 主动打开 Workspace

- 若当前 Session 曾打开工作视图，按策略恢复最近标签；
- 若尚未打开标签，普通任务从右侧导航入口打开 `context.md`；
- 助理从右侧导航入口打开 `MEMORY.md`；
- 若默认文件不存在，展示根目录说明或空状态；
- 主动打开不会自动选中“最新输出物”，避免用户误以为系统替他做了选择。

### 9.4 从文件树切换

- 点击文件后立即更新选中态和预览；
- 点击文件时打开或聚焦对应文件标签；
- 不新增聊天消息；
- 不修改文件内容；
- 不改变业务任务或 A2A 任务状态；
- 切换失败时保留文件头并展示错误，不跳到无关文件。

## 10. 文件类型预览

### 10.1 HTML

- 在受控沙箱中渲染；
- 预览内容可包含轻量浏览器栏：后退、前进、地址、刷新；
- 地址栏默认只读，不允许借此访问任意外网；
- 页面按预览区宽度自适应；
- 禁止默认获得宿主存储、剪贴板、摄像头、麦克风和跨域能力；
- HTML 的下载仍使用统一文件头操作，避免重复入口。

### 10.2 PPT

- 支持缩略图与当前页预览；
- 缩略图选择只影响当前文件内部页码，不影响文件树；
- 预览区域过窄时允许内容内部缩放或滚动，禁止撑宽页面；
- 正式产品可由服务端转换为图片、PDF 或安全画布格式。

### 10.3 Word

- 以只读分页或连续文档方式预览；
- 保留标题、段落、列表、表格、页眉页脚等关键结构；
- 不承诺与 Office 像素级一致；
- 转换失败时允许下载原文件。

### 10.4 Markdown

- 默认渲染为阅读视图；
- 支持标题、列表、代码块、引用、表格和链接；
- HTML 标签需过滤，避免脚本注入；
- 本期不提供编辑和保存。

### 10.5 JSON 与文本

- JSON 采用格式化只读预览；
- A2A 投影可在原始 JSON 上方增加人类可读摘要，但不得隐藏关键状态和版本；
- 大文件采用分段加载或虚拟滚动；
- 编码无法识别时说明原因并提供下载。

## 11. 下载规则

- 下载入口位于当前文件头；
- 只有可下载文件显示该入口；
- 下载前重新进行权限与有效性校验；
- 下载文件名默认与当前文件名一致；
- 同名版本通过 Artifact 版本或服务端响应区分；
- 下载中应防止重复触发；
- 下载失败展示可恢复提示，不关闭 Workspace、不改变当前选中项；
- 需要审计的文件必须记录用户、时间、Artifact、版本和结果。

## 12. 响应式交互

### 12.1 宽屏

- 对话和 Workspace 并排；
- Workspace 默认宽度应足以阅读内容画布，并允许按需打开右侧导航；
- 支持拖拽调整 Workspace 宽度；
- 内容画布和右侧导航分别设置最小宽度；
- 拖拽不得压缩到对话输入器或文件操作不可用。

### 12.2 中等窗口

当并排无法满足最小可用宽度时：

- Workspace 独占除全局侧边栏外的主工作区；
- 对话区暂时隐藏，不销毁；
- 关闭最后一个标签后返回原对话；
- 保留对话滚动位置、输入草稿、当前消息和选中文件；
- 不出现页面级横向滚动。

### 12.3 移动端

- 对话和 Workspace 采用单页切换；
- Workspace 内容画布全宽显示，右侧导航以覆盖层或单页显示；
- 全局侧边栏打开时应避免遮挡后仍误触底层内容；
- 标签栏、文件导航和内容画布各自按规则滚动；
- 返回对话后恢复原状态；
- 不通过将桌面双栏等比缩小来适配移动端。

## 13. 状态模型

客户端至少维护：

| 状态 | 含义 |
| --- | --- |
| `workspaceVisible` | Workspace 是否可见；隐藏时标签和目录状态仍可保留。 |
| `tabs` | 已打开的文件或 Browser 工作视图。 |
| `activeTabId` | 当前激活工作视图。 |
| `navigatorOpen` | 右侧文件导航是否打开。 |
| `outputsOpen` | 输出物浮层是否打开。 |
| `launcherOpen` | `+` 启动器是否打开。 |
| `workspaceRootId` | 当前模式的逻辑根节点。 |
| `expandedNodeIds` | 当前展开的文件夹集合。 |
| `selectedNodeId` | 文件导航当前选中文件或目录。 |
| `workspaceWidth` | 宽屏下用户调整后的宽度。 |
| `previewStatus` | `idle/loading/ready/converting/error/forbidden/expired`。 |

状态规则：

- `workspaceVisible` 与 `tabs` 相互独立，允许“隐藏但保留标签”和“显示无标签启动器”；
- 关闭最后标签同时清空并隐藏，点击 Workspace 按钮隐藏则不清空；
- 普通任务之间分别保存标签和选中项，不串用 Session 状态；
- 普通任务和助理分别保存展开状态；
- 路由或模式切换必须重新校验 `workspaceRootId` 与 `selectedNodeId`；
- 关闭右侧导航不清空标签；关闭最后标签时同步关闭导航、输出物浮层和启动器；
- 新建普通任务时清空上一任务的选中项，并默认定位新 Session；
- 文件被删除或权限撤销后，选中项进入明确失效状态，不自动切到无关文件。

## 14. 正式数据与接口要求

### 14.1 WorkspaceNode

至少包含：

- `node_id`
- `workspace_id`
- `parent_node_id`
- `node_type`: `folder/file/virtual_file`
- `display_name`
- `object_ref`
- `mime_type`
- `size`
- `created_at`
- `updated_at`
- `version`
- `permission_policy_id`

### 14.2 Artifact

至少包含：

- `artifact_id`
- `owner_user_id`
- `source_session_id`
- `source_message_id`
- `workspace_node_id`
- `file_name`
- `mime_type`
- `size`
- `storage_ref`
- `preview_status`
- `version`
- `created_at`
- `retention_policy`

### 14.3 必需服务能力

- 获取当前模式根节点；
- 分页获取子节点；
- 获取节点元数据和面包屑路径；
- 获取安全预览；
- 获取下载授权或短期下载地址；
- 订阅节点新增、转换完成、权限变化和过期事件；
- 基于稳定 ID 从消息卡片定位节点；
- 记录预览、下载和敏感访问审计。

客户端不得通过扫描文件名猜测 Artifact，也不得把前端目录树当作唯一文件存储。

## 15. 权限与安全

1. 用户只能看到当前根目录下有权访问的节点；
2. 助理不得扩大用户在普通任务、项目平台或 A2A 服务中的权限；
3. HTML、Markdown 和富文本必须进行内容隔离与注入防护；
4. 文件下载、预览地址和缩略图地址不得永久公开；
5. 敏感文件可按策略禁止预览、禁止下载或要求再次确认；
6. 权限撤销应及时使已打开预览失效；
7. A2A 文件只共享任务所需最小字段，不共享整个 Assistant 目录；
8. `MEMORY.md` 和 `USER.md` 默认仅用户本人及其个人助理可访问；
9. 日志不得记录完整敏感文件内容或临时下载令牌。

## 16. 异常处理

| 场景 | 产品行为 |
| --- | --- |
| 根目录加载失败 | 对话保持可用；Workspace 展示失败原因和重试。 |
| 目录为空 | 展示当前目录为空，不虚构示例文件。 |
| 文件转换中 | 展示转换状态，可继续切换其他文件。 |
| 文件不可预览 | 保留文件头；若允许则提供下载。 |
| 文件已过期 | 展示过期说明和重新生成入口（若业务允许）。 |
| 权限被撤销 | 立即停止返回内容，进入无权限状态。 |
| 下载失败 | 展示失败提示，可重试，不关闭 Workspace。 |
| 卡片引用失效 | 说明文件不可用，不自动打开其他同名文件。 |
| 网络中断 | 已安全缓存内容可只读查看；新请求展示离线状态。 |
| 同名文件 | 以稳定 ID 和版本区分，不静默覆盖。 |
| 文件树节点很多 | 分页、懒加载或虚拟滚动，不一次加载全部。 |

## 17. 可访问性

- Workspace 使用可识别的补充区域语义；
- 文件树使用树或导航语义，并提供明确名称；
- 所有图标按钮必须有可读名称；
- 键盘可完成打开、关闭、展开、收起、选择文件和下载；
- 焦点进入 Workspace 后应落在标题或选中文件，关闭后返回触发按钮；
- 选中态不能只依靠颜色表达；
- 拖拽宽度必须提供键盘等价操作或预设宽度；
- 缩放到 200% 时核心操作仍可用。

建议记录：

- Workspace 主动打开率与卡片触发打开率；
- 输出物生成后卡片点击率；
- 从文件树切换文件的次数；

- 预览转换成功率、失败率和重试率；
- 下载触发率与失败率；

不再记录旧版“模块菜单切换”和“变更入口点击”；新增标签打开、去重聚焦、最后标签关闭和 Browser 使用指标。

## 19. 验收标准

### 19.1 统一性

- 普通任务与助理使用同一个 Workspace 工作台组件；
- 双层导航、顶部标签、输出物浮层、右侧目录、内容画布和关闭动作一致；
- 两种模式只因目录和文件能力不同产生内容差异；
- 不出现旧版模块菜单、变更一级入口、终端、底部面板或侧边任务；
- 一级顶栏只保留输出物和 Workspace 两个固定按钮，二级栏只保留一个文件夹目录按钮；
- 隐藏 Workspace 后恢复原有标签、激活项和目录开关状态；
- 关闭最后标签时 Workspace 与右侧导航自动关闭；
- 不出现助理专属的独立协作事项右侧面板。

### 19.2 普通任务

- 新建任务后 Workspace 定位该 Session 目录；
- `context.md`、`attachments/`、`outputs/` 层级正确；
- 生成 HTML、PPT、Word、Markdown 后聊天区出现卡片，文件进入 `outputs/`；
- 生成完成不会自动打开 Workspace；
- 点击 HTML 卡片后打开受控 Browser；点击其他卡片后打开对应文件标签；
- 跨天继续 Session 不改变目录创建日期；
- 切换普通任务不会串用文件选择或输出物。

### 19.3 助理

- 进入助理时使用唯一长 Session；
- Workspace 根目录为 `Assistant/`；
- 默认可见规则、用户偏好、长期记忆、每日记忆、协作任务投影和助理输出物；
- 查询待办只在对话中返回结果，不强制打开 Workspace；
- 点击某个待办后定位对应协作任务文件；
- 默认不展示全部普通任务目录。

### 19.4 预览与下载

- HTML 采用受控 Browser 并可打开源文件；PPT、Word、Markdown 采用对应只读预览；
- Browser 不允许用户输入网址或访问任意外部页面；
- JSON 和文本可读；
- 当前文件头展示名称、元数据、路径和适用操作；
- 下载基于当前文件，失败不丢失选择；
- 同名文件按稳定 ID 或版本区分；
- 无权限、转换中、失败、过期均有明确状态。

### 19.5 响应式

- 宽屏下聊天和 Workspace 可并排，宽度可调整；
- 中等窗口下 Workspace 独占主工作区，关闭后恢复原对话；
- 移动端采用单页/单列可操作布局；
- 所有支持尺寸无页面级横向滚动；
- 模式、文件和视图切换后保留合理状态。

## 20. 当前 Demo 与正式产品的差异

当前 Demo：

- 使用前端 Mock 生成 HTML、PPT、Word、Markdown；
- 用前端对象模拟 Workspace 目录与 Artifact；
- 文件下载为前端模拟；
- 固定日期和任务剧本只用于演示；
- 普通任务和助理已经复用同一个 `WorkspaceWorkbench` 组件及状态机；
- 普通任务生成物进入当前 Session 的 `outputs/`；
- 助理展示 Assistant 规则、记忆、协作任务和输出物；
- 顶部实现工作视图标签、`+` 启动器、输出物浮层和右侧文件导航；
- HTML 卡片默认打开受控 Browser，Browser 地址只读并可跳转源文件；
- 已移除旧版模块菜单、变更、来源、底部面板、终端和侧边任务。

正式产品仍需接入 Session、Workspace、Artifact、Memory、权限、预览转换、下载和审计服务。Demo 验收只代表交互方向可验证，不代表数据可靠性、安全性或服务端能力完成。

## 21. 待确认事项

1. Workspace 宽度是否按用户、设备和模式分别持久化；
2. 普通任务首次打开时默认选中 `context.md`，还是展示任务目录说明；
3. Assistant 首次打开默认选中 `MEMORY.md` 的权限和空内容策略；
4. PPT 预览采用服务端图片、PDF 还是专用转换服务；
5. 不可预览文件是否统一提供安全下载；
6. 用户是否可以在未来直接编辑 Markdown，以及写回、版本和冲突规则；
7. 助理临时打开普通任务文件后，界面如何清楚表达“临时跨根访问”。
